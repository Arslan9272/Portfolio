# Arslan — Portfolio

A personal portfolio site built with Next.js 16, TypeScript, and Tailwind CSS v4, with Framer Motion for animation and React Three Fiber for 3D — a dark, chrome-and-glass design showcasing full-stack and AI/ML/CV work.

## Usage

```bash
npm run dev     # start the dev server at http://localhost:3000
npm run build   # production build
```

## Content

All personal content (name, role, about, projects, experience, skills, links) lives in `content/site.ts` — edit that file to update the site.
